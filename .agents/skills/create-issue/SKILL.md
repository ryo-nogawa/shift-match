# Issue 作成

1. `.github/ISSUE_TEMPLATE/` の現在の内容を読み、依頼に合うテンプレートを選びます。不具合には `bug.md`、機能追加・改善には `feature.md` を使います。種類が判断できなければユーザーに確認します。
2. テンプレートの見出しとチェック項目を保って本文を作ります。確認できない事実は推測で埋めず、「未確認」と記載します。起票に不可欠な情報が欠けている場合だけ質問します。
3. 内容が分かる簡潔なタイトルを付けます。テンプレートの frontmatter に指定されたラベルがあれば、既存のラベルを適用します。ラベル自体は作成しません。
4. Issue の作成まで依頼されている場合は、対象リポジトリを確認し、本文をファイルに保存して `gh issue create --title ... --body-file ...` などで起票します。下書きだけの依頼なら起票しません。
5. 起票後は Issue の URL、タイトル、使用したテンプレートとラベルを報告します。起票できなかった場合は理由と作成済みの下書きを伝えます。

テンプレートをこのスキルに複製せず、起票時点の `.github/ISSUE_TEMPLATE/` を正とします。

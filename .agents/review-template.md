# コードレビューテンプレート

結果は日本語で報告します。

## レビュー対象

- 対象と比較範囲
- 確認した規約・仕様
- 実行した確認コマンドと結果（未実行の場合はその旨）

## 評価結果

| レベル               | 対象ファイル         | 指摘内容                   | 改修方針         |
| -------------------- | -------------------- | -------------------------- | ---------------- |
| MUST / SHOULD / WANT | ファイルパスと行番号 | 問題、根拠、発生条件、影響 | 具体的な修正方法 |

指摘は 1 件につき 1 行とし、MUST → SHOULD → WANT の順に並べます。各レベルに指摘がなければ、そのレベルで「該当なし」の行を記載します。該当ファイルがない場合は「—」とします。

### レベルの判定基準

- **MUST**：修正しないとコードが動かない問題、明確な規約違反、攻撃を受ける可能性が高いセキュリティ問題。
- **SHOULD**：可読性・保守性のために修正を推奨する問題。
- **WANT**：任意の改善提案。

確認できた事実と推測を区別し、根拠のない指摘は載せません。

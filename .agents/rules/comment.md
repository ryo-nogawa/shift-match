# コメント

## 基本方針

- Javadoc の説明だけでは実装の意図や理由が読み取れない箇所には、コメントで補記する
  - 対象例：アルゴリズム上の工夫、既知の制約への回避策、外部仕様への対応など
- コメントには「何をしているか」ではなく「なぜこの実装にしたか」を記載する
  - 「何をしているか」はコード自体や `{@link}` を参照すればわかるため、コメントに重複して書く必要はない

## 記載例

```java
// NG：「何をしているか」を説明しているだけ
// カウンタをインクリメントする
counter.incrementAndGet();

// OK：「なぜこの実装にしたか」を説明している
// 複数スレッドからの同時アクセスでカウントがずれないよう、AtomicInteger でインクリメントする
counter.incrementAndGet();
```

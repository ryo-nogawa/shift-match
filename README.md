# Shift Match

従業員の希望をもとに、1日分のシフトを自動で組み立てる Web アプリケーションです。

## 開発状況

要件整理段階です。以下に記載する機能は開発予定であり、実装済みではありません。

## 概要

管理者が各従業員の希望（6 つの勤務枠ごとに ◎ 希望／○ 可能／× 不可）を入力すると、業務ルールをすべて満たし、かつ希望を最も多く反映した割り当て（6 つの枠に 8 名）を提案します。

- 入力から結果表示まで 1 画面で完結します
- データベースを使用しないため、起動コマンドのみで利用できます
- 条件を満たす組み合わせが存在しない場合は、その旨を表示します

## 技術スタック

Java 25 / Spring Boot 4.1.1 / Thymeleaf / Maven（データベースは使用しません）

## 起動方法

JDK 25 が必要です。Maven は同梱の Maven Wrapper を使用するため、別途インストールは不要です。

```bash
git clone <このリポジトリのURL>
cd shift-match
./mvnw spring-boot:run
```

起動後、ブラウザで http://localhost:8080 にアクセスしてください。

## テスト実行方法

```bash
./mvnw test
```

## 使い方

1. 表に従業員名と、6 つの枠ごとの希望（◎／○／×）を入力します
2. 人数が足りない場合は「行を追加」で入力欄を増やします
3. 「シフトを作成」を押すと、同じ画面に割り当て結果が表示されます

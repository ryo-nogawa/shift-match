# Shift Match

従業員の勤務できる時間帯をもとに、1日分のシフトを自動で組み立てる Web アプリケーションです。

## 開発状況

[要件定義](docs/specifications.md) の機能 F-1〜F-6（時間帯の入力、入力行の追加・削除、シフト作成、結果表示、不成立の通知）を実装済みです。

## 概要

管理者が各従業員の「勤務できる時間帯（開始・終了）」または「休み」を入力すると、業務ルールをすべて満たす割り当て（6 つの枠に 8 名）を 1 つ提案します。

- 従業員は、枠の勤務時間が入力した時間帯に完全に含まれる場合だけ、その枠に割り当てます（H-3）。「休み」の従業員は割り当てません
- 案は「ずれの合計」（各人の入力した時間帯の長さ − 割り当てた枠の勤務時間、分）が最も小さいものを採用します。0 が最良です。同点の場合は、勤務開始が早い枠ほど入力画面の上にいる人を優先します
- 休憩時刻は労働基準法第 34 条に基づき自動で割り当てます
- 入力から結果表示まで 1 画面で完結します
- 最新 1 件の従業員入力を H2 データベース（`./data/`）に自動保存し、画面表示時に復元します（利便性のため。シフト結果は保存のみで復元されません）
- 条件を満たす組み合わせが存在しない場合は、その旨を表示します

## 技術スタック

Java 25 / Spring Boot 4.1.1 / Thymeleaf / Maven / H2 Database（入力の保存・復元用）

## 起動方法

JDK 25 が必要です。Maven は同梱の Maven Wrapper を使用するため、別途インストールは不要です。

```bash
git clone <このリポジトリのURL>
cd shift-match
./mvnw spring-boot:run
```

起動後、ブラウザで http://localhost:8080 にアクセスしてください。

## テスト実行方法

```bash
./mvnw test
```

## 使い方

1. 表に従業員名を入力し、勤務できる時間帯を「開始」「終了」のプルダウン（7:30〜18:30、30 分単位）から選びます。その日に勤務しない人は「休み」にチェックします
2. 入力欄は最初から 12 行表示されます。不要な行は「削除」で消せます（消した行は「行を追加」で戻せます。最大 12 行）
3. 「シフトを作成」を押すと、同じ画面に割り当て結果（氏名・勤務時間・休憩時間、ずれの合計、未出勤者）と、その選定根拠（各人のずれ・入れる枠・未出勤者の理由）が表示されます
